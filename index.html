Sequential Circuits

Unlike combinational circuits, the output depends on the current inputs and the stored state from previous inputs.

Memory • Latches & Flip-Flops

What is a Sequential Circuit?

Core Idea

A sequential circuit has memory, so its present output can depend on the current input, previous input, previous output, clock, and stored state.

CombinationalNo memory. Output depends on the current inputs only.
SequentialUses memory. Output depends on current inputs and previous state.
Why storage?To remember the last state of the circuit.
Storage elements are the basic building blocks used in sequential logic. The course identifies latches and flip-flops as storage elements.

Storage Elements: Latches and Flip-Flops

Course Concept

Latches and flip-flops are storage elements used as building blocks of sequential logic. A flip-flop is a bistable device that can store one bit and has complementary outputs Q and Q′.

LatchSensitive to its input level/control signal. Examples: SR Latch and D Latch.
Flip-FlopChanges state in synchronization with a clock, commonly at a clock edge.
OutputsQ = 1, Q′ = 0 is the set state; Q = 0, Q′ = 1 is the reset/clear state.
Next topic in the course sequence: Clocked/Edge-Triggered SR Flip-Flop, JK Flip-Flop, and D Flip-Flop.

Flip-Flops

1-bit Memory

A flip-flop is a bistable storage element that can store one bit of binary data. It has two stable states and complementary outputs Q and Q′.

Set StateQ = 1 and Q′ = 0.
Reset StateQ = 0 and Q′ = 1.
Clocked OperationFlip-flops respond in synchronization with a clock, commonly at a clock edge.
The course describes flip-flops as improved storage elements that respond only on clock edges, helping avoid changes caused by continuous input changes.

Triggering & Clocking

Level vs Edge

A trigger is a control signal used to initiate an action. The course distinguishes level triggering from edge triggering.

Level TriggerAn action is initiated on a high or low level.
Edge TriggerAn action is initiated on a positive or negative transition.
ClockA series of pulses (square wave) used to synchronize actions; triggers are generally taken from its edge.

Counters

A counter is a sequential circuit that moves through a defined sequence of binary states when clock pulses are applied.

State • Clock • MOD

What is a Counter?

Core Idea

A counter advances from one binary state to the next with clock pulses. The course covers asynchronous (ripple), synchronous, up/down, and MOD counters.

AsynchronousFlip-flops do not receive the same clock edge; the change ripples through the stages.
SynchronousThe stages operate from a common clock.
MOD-NThe counter has N distinct states before the sequence repeats.
Example 3-bit sequence000 → 001 → 010 → 011 → 100 → 101 → 110 → 111 → 000

Registers

A register is a group of flip-flops used to store binary data. Each flip-flop stores one bit and the group shares a common clock.

Storage • Load • Shift

What is a Register?

Core Idea

The course defines a register as a group of flip-flops used to store binary information. An n-bit register uses n flip-flops, because each flip-flop stores one bit.

4-bit Register4 flip-flops → 4 bits of stored data.
8-bit Register8 flip-flops → 8 bits of stored data.
PurposeTemporarily store, shift, or transfer binary data.
TypeDescriptionExample Use
Parallel RegisterAll bits loaded or read simultaneously.Fast data storage
Serial RegisterBits loaded one by one.Communication systems
Shift RegisterData shifts between neighboring flip-flops.Data transfer / conversion
Universal Shift RegisterCan shift left/right and load data in parallel.Complex data handling
